🧬 What is Neuroevolution?

Neuroevolution is a method of training neural networks using principles from biological evolution. Instead of traditional learning algorithms (like backpropagation), it mimics natural selection:

  1. Initialize: Create a neural network with random weights
  2. Evaluate: Test the network by playing a game episode and measuring performance (fitness)
  3. Mutate: Randomly modify the weights (like genetic mutations)
  4. Select: Keep networks that perform well, discard poor performers (survival of the fittest)
  5. Repeat: Continue until the network discovers winning strategies

🏗️ Network Architecture

<strong>Simple Networks:</strong> 2-3 layer feedforward networks, fast but limited

<strong>Convolutional Networks (CNN):</strong> Process pixel input like human vision, slower but more powerful

Input: Game screen pixels (preprocessed to 84×84 grayscale)

Output: 4 or 6 buttons (LEFT, RIGHT, UP, DOWN, JUMP, RUN)

👁️ Vision System (16×7 Grid)

The agent extracts game state from NES RAM into a 16×7 tile grid centered on Mario:

  • Horizontal: 4 tiles behind, 11 tiles ahead (optimal lookahead for jump planning)
  • Vertical: 3 above, 1 current row, 3 below (sufficient vertical awareness)
  • Tile Encoding: Empty (0.0), Solid blocks (1.0), Enemies (-1.0)
  • Context Features: +8 engineered inputs (enemy_left_dist, enemy_right_dist, ground_dist, pit_dist, obstacle_dist, is_on_ground, y_position, enemy_nearby)
  • Total Input: 112 vision + 8 context = 120 values per decision

For CNN: Vision reshaped to 7×16 2D grid before conv layers. For feedforward/NEAT: Flattened to 1D then concatenated with context.

🏆 Fitness Function & Evolution Strategy

Fitness Formula: distance1.5 + (score × 2) + milestones - death_penalties

  • Distance Rewards: Exponential (x1.5) to heavily favor progress right
  • Score Multiplier: 2× for enemy stomps (encourages combat over avoidance)
  • Milestone Bonuses: +200 at 50px, +500 at 100px, +1000 at 200px, +2000 at 400px, +5000 at 800px
  • Death Penalties: -50 for enemy hits, -100 for getting stuck (no progress for 60 frames)
  • Adaptive Mutation: 0.05 rate when improving fitness, 0.1 normal, 0.3 when performance drops or stuck
  • Elite Preservation: Best network saved as "champion", restored if fitness drops below 30% of best
  • Local Minima Escape: Full reset with priors after 5 consecutive generations at same distance

⚡ Technical Architecture

  • <strong>Emulator:</strong> NES.js (JavaScript NES emulator)
  • <strong>Preprocessing:</strong> Screen capture → grayscale 84×84 → pixel normalization
  • <strong>Population Size:</strong> 50 networks per generation
  • <strong>Generation Time:</strong> Varies by architecture (1-5 seconds)
  • <strong>Mutation Rate:</strong> 10-20% of weights mutated per generation
  • <strong>Convergence:</strong> Typically finds good strategy in 20-100 generations

🧠 Neural Network Basics

A neural network is a computational model inspired by biological brains. It consists of layers of artificial neurons that process information:

  • Input Layer: Receives raw data (in our case, Mario's vision of the game world)
  • Hidden Layers: Process and transform the data through mathematical operations
  • Output Layer: Produces decisions (which buttons to press)

Each neuron connection has a weight - a number that determines how much influence one neuron has on another. Learning means adjusting these weights to make better decisions.
