Bokeh

🎨 What is Bokeh?

Bokeh is a powerful Python library for creating interactive, browser-based visualizations. It's designed to make it easy to create elegant, publication-quality plots that work seamlessly in web browsers without requiring you to write any JavaScript code.

⚙️ How Does Bokeh Generate Charts?

1. Python API: You write Python code using Bokeh's high-level API (figures, glyphs, tools). 2. JSON Serialization: Bokeh converts your Python objects into a JSON specification that describes the visualization. 3. BokehJS Rendering: The JSON is sent to BokehJS (JavaScript library) which renders the actual chart in the browser using HTML5 Canvas or WebGL. 4. Interactivity: BokehJS handles all user interactions (pan, zoom, hover) entirely in the browser for smooth performance.

🐍 Why Use Bokeh with Python Instead of Pure JavaScript?

Even though Bokeh ultimately renders using JavaScript:

  • Data Processing Power: Python excels at data manipulation with Pandas, NumPy, and NetworkX. Process millions of rows before visualization.
  • Scientific Ecosystem: Leverage Python's rich scientific libraries (SciPy, scikit-learn, statsmodels) for analysis before plotting.
  • High-Level API: Bokeh's Python API is more intuitive and expressive than writing raw JavaScript visualization code.
  • Code Reusability: Same Python code works in Jupyter notebooks, web apps, and scripts - write once, visualize anywhere.
  • Complexity Abstraction: Bokeh handles the tedious JavaScript plumbing (event handlers, canvas drawing, scale calculations) for you.
  • With PyScript: Run this Python code directly in the browser - no backend server needed! Best of both worlds.

🔄 The PyScript + Bokeh Workflow

In this example, PyScript runs the Python code in your browser using WebAssembly. The Python code creates a Bokeh plot, which gets serialized to JSON. BokehJS (already loaded in the page) receives the JSON and renders the interactive chart. The result: you get the power of Python's data processing and JavaScript's rendering performance, all without a backend server!

💡 Interactive Features

Try interacting with the chart above! You can: pan (click and drag), zoom (mouse wheel or box zoom tool), hover (see exact values), and reset (return to original view). All these features work entirely in the browser thanks to BokehJS.
